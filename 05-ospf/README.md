# OSPF Labs

**Packet Tracer files:**
- `ospf-single-area-topology.pkt`
- `ospf-backbone-area-topology.pkt`

## Practiced
- OSPF process configuration
- Wildcard masks
- Network advertisement
- Single-area OSPF
- Backbone/multi-area concepts
- Neighbor verification with `show ip ospf neighbor`
- OSPF routes in `show ip route`

## Goal
Build OSPF adjacencies and allow routers to learn remote networks automatically.
